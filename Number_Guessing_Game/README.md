# 🎯 Number Guessing Game (Python)

A simple command-line based number guessing game written in Python.

## 📌 Features
- Random number generation (1–100)
- User input validation
- Hint system (Too High / Too Low)
- Attempt counter

## 🛠 Technologies Used
- Python 3
- random module

## ▶ How to Run
python number_guessing_game.py

## 🧠 Learning Outcomes
- Python loops
- Conditional statements
- Exception handling
- Random number generation
